## Known gaps against the phase-0 packet (scheduled)

- **Editorial visual direction (revisions 3/4, docs 07–09): applied (slice R3).** Ivory paper, ink `#171B18`, deep green for the
  main action, flat 0–2px geometry, fine rules instead of rounded cards, tracked labels; open-licensed (SIL OFL) webfonts — Bodoni
  Moda display serif with optical sizing and Inter UI sans (Inter's latin-ext face carries `₦`; Bodoni Moda does not, so the UI sans
  follows it in the serif stack and all amounts use the sans). Masthead header (THRIFT working descriptor), editorial cover at `/`
  with one focal image that is an actual listed piece (no generated or stock imagery), `/discover` → catalogue, item cards with
  full titles and explicit sale mode/“Sponsored” text, serif page and section headings, quiet seller/staff workspace with a
  disclosure menu on narrow screens. Checked: text contrast of the token pairs used (all ≥ 4.5:1; strong rule 3.43:1 for control
  boundaries), no page-level horizontal scroll at 320px on public pages, full E2E suite. Still pending: keyboard/screen-reader
  audit with real users, 200% text enlargement review, licensed brand fonts (D01).
- **Same-seller multi-item checkout group (doc 06): built — ADR-0009.** A bag (interest only, `max_bag_items` draft 20)
  and a per-shop checkout that holds every piece or none, in listing-id lock order, with the confirmed prices; the pending
  order is the checkout group and every item has its own hold, so expiry, cancel, retry, late payment and seller
  cancellation act on the whole group (never a partial sale). One parcel and one delivery fee per order; weight-based
  courier pricing is not modelled yet (D09). Partial per-item refunds are not built (the split is frozen for them).
- **Lock order (doc 06): decided — ADR-0008.** The build keeps its consistent auction → offer thread → stock order;
  deadlock freedom comes from consistency, and every path that touches both takes the auction first.
- **Auction custody (doc 06): verified and tightened.** Enforced through fixed sale mode, guarded seller edits and
  winner allocation in the closing transaction. Found and fixed: moderation removal or shop suspension left auctions
  running (the closing job then failed to allocate and stuck); bids didn't check the shop's status. See ADR-0008.
